# Veeam Kasten (Kasten K10)

> Veeam Kasten (formerly Kasten K10) is an enterprise-grade, Kubernetes-native data
> protection platform providing backup and recovery, disaster recovery, application
> mobility, ransomware resilience, and virtual-machine (KubeVirt) protection through
> policy-driven automation. It is deployed inside the customer's own Kubernetes
> cluster and driven through Kubernetes Custom Resources and an in-cluster REST API.

## Authentication

- Bearer token via any credential the Kubernetes API server can verify (typically a ServiceAccount token): `Authorization: Bearer <token>`.
- Additional dashboard auth: Basic (htpasswd), OpenID Connect, OpenShift OAuth, LDAP/Active Directory.

## Tools and source

- [kastenhq GitHub organization](https://github.com/kastenhq): first-party open-source projects.
- [kubestr](https://github.com/kastenhq/kubestr): CLI to identify/validate/benchmark Kubernetes storage (CSI, snapshots, FIO).
